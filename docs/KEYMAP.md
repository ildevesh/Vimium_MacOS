# Keymap

Super = Hyper = `⌘ + Control + Option + Shift`.

| Shortcut | Action |
|---|---|
| Super+V | Toggle Vim mode |
| Super+Space | Command palette |
| `w` | Scroll up |
| `s` | Scroll down |
| `a` | Scroll left |
| `d` | Scroll right |
| `W` | Full-page up |
| `S` | Full-page down |
| `h` | Back |
| `l` | Forward |
| `⌘⇧A` | Back |
| `⌘⇧D` | Forward |
| Super+Q | Next tab |
| Super+E | Previous tab |
| Tab+Q | Move tab to a new window where supported |
| `o` | Address/search bar |
| `O` | New tab |
| `~` | Edit URL |
| F4 | Launch/focus Shottr |

`⌘W`, `⌘S`, and other important standard macOS shortcuts are intentionally
not globally remapped.

Scroll-to-top and scroll-to-bottom shortcuts are intentionally omitted.
