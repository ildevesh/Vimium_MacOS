# Compatibility

| Application | Current status |
|---|---|
| Finder | Core mappings + command palette + current-folder search |
| Safari | Core mappings + command palette + Tab+Q |
| Google Chrome | Core mappings + command palette + Tab+Q |
| Chromium | Generic browser mappings |
| Dia | Partial; custom handling remains |
| Other apps | Generic mappings + fallback commands where available |

Application behavior depends on what macOS Accessibility and native menus expose.
A Chromium-based app is not guaranteed to expose the same menu structure as Chrome.
