# Contributing

## Principles

1. Do not hijack normal text entry.
2. Do not unnecessarily replace standard macOS shortcuts.
3. Prefer Accessibility/native menu actions over coordinate automation.
4. Keep application-specific exceptions isolated.
5. Avoid unnecessary background polling.

## Testing

Test at least Finder, Safari, Google Chrome, and one additional application.
Verify Vim mode, text fields, standard macOS shortcuts, palette open/close,
and command execution.

## Pull requests

Describe the feature/change, tested applications, changed shortcuts, and known
compatibility limitations.
