# Changelog

## 0.1.0 — 2026-09-25

Initial public repository packaging.

### Included

- Hyper/Super master toggle.
- Accessibility-aware text-input protection.
- Keyboard scrolling.
- Back/forward navigation.
- Application-aware tab switching.
- Tab+Q → move-tab routing.
- Browser URL navigation mappings.
- Spotlight-style command palette.
- Native application menu discovery.
- Generic fallback commands.
- Finder current-folder file/folder search.
- Shottr launcher shortcut.
- Direct URL/file/folder opening from the command palette.

### Planned

- Browser bookmark/history search.
- More Dia-specific handling.
- Better application compatibility.
